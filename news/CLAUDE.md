# news

主題：待補（新聞資料的蒐集與分析）

> 這個專案放在 `ntu-youbike` repo 的 `news/` 資料夾，和根目錄的台大 YouBike 專案、`climbing/` 抱石地圖互相獨立。
> 以下的路徑都是相對於 `news/`。

## 資料夾規則
- data/raw/：原始資料。只存「媒體、日期時間、標題、網址」四個欄位，**不得儲存新聞全文**。原始資料寫入後不再修改。
- data/processed/：由 src/ 中的程式從 raw 清理、去重後產生，不手動編輯。
- src/：所有 Python 程式都放這裡，包含撈資料、清理、計數、標註。**不要只在對話中執行一次性程式碼**；任何處理步驟都要存成 src/ 下的 .py 檔，確保可重跑。
- output/：每次分析或輸出另存新版本資料夾 output/v1/、output/v2/…，**舊版不覆蓋、不刪除**。使用者決定採用的版本才複製到 output/final/，未經使用者同意不得改動 final。
- docs/：AI 自動產生的報告，以及使用者親手寫的文件。不得改寫使用者親手寫的文件。
- logs/：過程紀錄，由紀錄系統自動寫入。

## 工作原則
- 產生新輸出前，先檢查 output/ 下最新版本號，用下一個號碼建立新資料夾。
- 機密資訊（API 金鑰等）放 .env，不寫進程式碼，不 commit。
- 重要變更完成後做 git commit，訊息清楚說明做了什麼。
